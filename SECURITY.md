# Security policy

Please do not place private evaluation data, credentials, or unreleased model output
in a public issue. Report vulnerabilities through GitHub's
[private vulnerability reporting](https://github.com/appleweiping/metricguard/security/advisories/new). Include
affected versions, impact, reproduction steps, and a suggested fix
when available.

MetricGuard does not make network requests. Treat third-party metric plugins and case
files as untrusted input and run them with permissions appropriate to their source.
