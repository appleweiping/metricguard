# Support

- Use [Discussions](https://github.com/appleweiping/metricguard/discussions) for usage questions and design ideas.
- Use [Issues](https://github.com/appleweiping/metricguard/issues) for reproducible defects and accepted feature work.
- Use [private vulnerability reporting](https://github.com/appleweiping/metricguard/security/advisories/new) for security concerns.

Support is best-effort. Public reports should use synthetic cases and include metric configuration, policy, seed,
optimization direction, and resampling settings without disclosing private evaluation data.
