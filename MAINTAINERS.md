# Maintainers

MetricGuard is currently maintained by [@appleweiping](https://github.com/appleweiping).

Maintainers review metric semantics, statistical claims, compatibility, plugin trust, documentation, and release
evidence. Contributions are accepted through pull requests; a maintainer remains accountable for every merged change.

Security reports must use [private vulnerability reporting](https://github.com/appleweiping/metricguard/security/advisories/new).
